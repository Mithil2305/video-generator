## 2. Timing & Architectural Analysis

### Pure Function of Time ($t$)
All 26 templates in `NullMotion/public/` adhere strictly to the offline renderable timeline architecture:
- Every template initializes a paused GSAP timeline: `const tl = gsap.timeline({ paused: true, ... });`
- Timelines register to `window.__timelines['root'] = tl` for headless control.
- No template runs a background timer, interval, or ticker when loaded headlessly.
- Live playback (`tl.play()`) is only triggered conditionally in interactive browser previews when `location.hash === '#play'`.

### Data Parameterization Strategy
Currently, several templates contain authored placeholder strings and mock data (e.g. `'10x faster'`, `'STOCK MARKET'`, `'Veo 3.1'`, `'Publish'`). Under Step 2 and Step 3:
1. **Data Binding**: The template DOM nodes will be bound to `scene.data` passed from `plan.json`.
2. **Zero Inventions**: If optional fields are absent, elements are cleanly omitted; missing required fields will fail schema validation immediately.
3. **Hardcoded Figure Removal**: Literal values like 'Surge 10x' in `13-compare-bars` will be derived strictly from `data.bars`.

### Showcase Directory Verification
The `NullMotion/showcase/` directory contains sample rendered references, cut lists, and drafts (`references/`, `media/`), but **no HTML/JS motion templates**. All 26 motion templates reside cleanly in `NullMotion/public/`.
